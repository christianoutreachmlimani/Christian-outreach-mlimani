CHRISTIAN OUTREACH MINISTRIES WORLDWIDE – MLIMANI
Website starter package

WHAT IS HERE
- index.html = all website sections and text
- style.css = colours, layout and responsive design
- script.js = mobile menu and year
- assets/ = church logo and leadership photos

EDITING
You can edit text in index.html. You can replace images in assets/ while keeping the same filenames, or update the image filenames in index.html.

FREE PUBLISHING PLAN
1. Create a free GitHub account at github.com.
2. Create a new PUBLIC repository. A simple name such as christian-outreach-mlimani works.
3. Upload all files and the assets folder from this package.
4. In the repository, open Settings > Pages.
5. Choose Deploy from a branch, select the main branch and the / (root) folder, then Save.
6. GitHub will provide the public website address, usually in the form https://YOURUSERNAME.github.io/REPOSITORY-NAME/

IMPORTANT
Do not put passwords or private account credentials into the website files.

NEXT STEP
The assistant can guide you through every GitHub step on your phone or computer. You do not need to know coding.
